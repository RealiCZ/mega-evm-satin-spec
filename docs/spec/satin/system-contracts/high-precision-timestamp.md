# High-Precision Timestamp

{% hint style="warning" %}
**Unstable** — Satin is under active development: everything on this page may change before Satin is frozen.
This page is a stub. It lists what the page will specify; the specification text is written after the outline is reviewed.
{% endhint %}

Abstract: The High-Precision Timestamp contract, unchanged from the Rex era: its address, interface and storage layout, whose reads follow the Satin Oracle and detention rules.

## Specification

The rules this page will specify, by their proposed ids:

- `SATIN-HPTS-001` — Address, interface, storage layout and service semantics as under Rex6; bytecode unchanged.
- `SATIN-HPTS-002` — Its reads of the Oracle's storage are Oracle reads under the Satin rules (service answer, cold price, detention).

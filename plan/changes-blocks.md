Where an implementation differs from the text of the Satin pages `satin/overview.md`, `satin/base-layer.md`, `satin/system-contracts/` and `satin/block/`, this list names the rule, the implementation, the place, and what must change.
(a) is mega-evm `4e39cfd6` (`a:` = `crates/mega-evm/src/`), on its revm fork at `4c8f0d43` (`revm:` = repository-relative paths); (b) is the `next/` workspace at mega-evm `f3d84454` (`b:` = `next/mega-evm2/src/`, `op:` = `next/op-evm2/src/`), on its evm2 fork at `390a3876` (`evm2:` = `crates/evm2/src/`).
Every row was rechecked against spec `d334ef8`; the Place column gives evidence at these implementation revisions. Rex6's reference code is mega-evm `d4c913c5`.
Closed rows keep their place and previous requirement after "Was:"; an earlier recorded closure keeps its revision, and newly closed rows name the revision checked here.
References inside "Was:" describe the earlier check, not the current source locations.
Changes counts include closed rows; Open includes latent rows, of which none remain.
